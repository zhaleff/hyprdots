## Contributing

Want your setup in here? Submit it at **[ricehubx.vercel.app/submit](https://ricehubx.vercel.app/submit)** with a screenshot, color palette and dotfiles link. Once approved it shows up on the site *and* in this index, which a bot refreshes every day.

```
submit → get reviewed → appear in the gallery + this README
```
